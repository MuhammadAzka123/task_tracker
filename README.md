## Cara Menjalankan

1. Melakukan Perintah Pada Terminal:

   flutter doctor

2. Clone repository GitHub:

   git clone https://github.com/MuhammadAzka123/task_tracker.git

3. Masuk ke folder project:

   cd mini_task_tracker

4. Melakukan Perintah Pada Terminal:

   flutter pub get

5. Menjalakan aplikasi menggunakan emulator:

   flutter run atau Menekan F5
